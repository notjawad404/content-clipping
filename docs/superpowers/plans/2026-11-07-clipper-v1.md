# Clipper v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Paste one YouTube podcast link into Claude Code and get finished 1080×1920 clips plus per-platform post captions, produced locally on an Apple M1.

**Architecture:** A Claude Code skill (`.claude/skills/clipper/SKILL.md`) orchestrates a local Python package (`clipper/`). Claude only does judgment work (choosing/scoring moments, writing hook text and post copy, visual QA). Deterministic Python handles download (yt-dlp), word-level transcription (parakeet-mlx), reframing (PySceneDetect + MediaPipe), captions (ASS via pysubs2) and rendering (one ffmpeg-full pass per clip). Every stage writes files under `jobs/<video_id>/`, so rerunning resumes.

**Tech Stack:** Python 3.12 (uv), yt-dlp[default] + Node 22, parakeet-mlx, scenedetect, opencv-contrib-python, mediapipe (Tasks API), pysubs2, PyYAML, jsonschema, pytest, Homebrew `ffmpeg-full`.

**Spec:** `docs/superpowers/specs/2026-11-07-clipper-design.md`

## Global Constraints

- Python 3.12 only (`requires-python = ">=3.12,<3.13"`); always run through `uv run …`. System Python 3.9.6 must never be used.
- Rendering and filters use Homebrew `ffmpeg-full` at `/opt/homebrew/opt/ffmpeg-full/bin` (keg-only). The plain `ffmpeg` formula lacks libass.
- yt-dlp uses the installed Node 22 as its JS runtime: `--js-runtimes node`.
- The project path contains a space (`Content Clipping`): every subprocess call passes arguments as a list, never a shell string. ffmpeg filtergraphs reference files by relative name with `cwd` set (no paths inside filtergraphs).
- Output: 1080×1920, 30 fps, H.264 High, yuv420p, AAC 48 kHz 192 kbps, `+faststart`; loudness −14 LUFS integrated, −1 dBTP.
- Captions and hook text stay inside the cross-platform safe zone: y ∈ [270, 1250], x ∈ [65, 960].
- Clip length default 20–90 s (target 30–60 s). Defaults: `max_clips: 8`, `min_score: 7.0`, max overlap 50%.
- Post captions: ≤ 5 hashtags (campaign-required tags first), campaign `required_text` and `creator_tag` always present, X ≤ 280 characters.
- Claude never writes timestamps; `clips.json` uses sentence IDs (`S0001`…), code derives times.
- Transcription is English-only: `mlx-community/parakeet-tdt-0.6b-v2`.
- Disk: refuse to start a job with < 5 GB free; `finish` deletes downloaded media.
- Unit tests never touch the network, models or ffmpeg-full. Anything that does is marked `@pytest.mark.integration` and runs with `uv run pytest -m integration`.
- Every commit message ends with the trailer line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```python
import os
import shutil
from pathlib import Path

PROJECT_ROOT = Path(__file__).resolve().parent.parent
CONFIG_DIR = PROJECT_ROOT / "config"
ASSETS_DIR = PROJECT_ROOT / "assets"
FONTS_DIR = ASSETS_DIR / "fonts"
SFX_DIR = ASSETS_DIR / "sfx"
MODELS_DIR = PROJECT_ROOT / "models"
JOBS_DIR = PROJECT_ROOT / "jobs"
OUTPUT_DIR = PROJECT_ROOT / "output"

FACE_MODEL_PATH = MODELS_DIR / "face_landmarker.task"
FONT_PATH = FONTS_DIR / "Montserrat-Black.ttf"
WHOOSH_PATH = SFX_DIR / "whoosh.wav"

FFMPEG_FULL_DIR = Path(os.environ.get("CLIPPER_FFMPEG_DIR", "/opt/homebrew/opt/ffmpeg-full/bin"))


def ffmpeg_dir() -> Path | None:
    if (FFMPEG_FULL_DIR / "ffmpeg").exists():
        return FFMPEG_FULL_DIR
    found = shutil.which("ffmpeg")
    return Path(found).parent if found else None


def ffmpeg_bin() -> str:
    d = ffmpeg_dir()
    return str(d / "ffmpeg") if d else "ffmpeg"


def ffprobe_bin() -> str:
    d = ffmpeg_dir()
    return str(d / "ffprobe") if d else "ffprobe"


def prepend_ffmpeg_to_path() -> None:
    """Child processes (parakeet-mlx, yt-dlp) must find ffmpeg-full before any other ffmpeg."""
    d = ffmpeg_dir()
    if d is None:
        return
    parts = os.environ.get("PATH", "").split(os.pathsep)
    if str(d) not in parts:
        os.environ["PATH"] = os.pathsep.join([str(d), *parts])
```

```python
"""Load style defaults, a campaign file and run overrides into one dict."""
from __future__ import annotations

import copy
from pathlib import Path
from typing import Any

import yaml

from clipper.env import CONFIG_DIR


class ConfigError(Exception):
    pass


def deep_merge(base: dict[str, Any], override: dict[str, Any]) -> dict[str, Any]:
    """Return a new dict: nested dicts merge, any other value in `override` replaces."""
    result = copy.deepcopy(base)
    for key, value in override.items():
        if isinstance(value, dict) and isinstance(result.get(key), dict):
            result[key] = deep_merge(result[key], value)
        else:
            result[key] = copy.deepcopy(value)
    return result


def _read_yaml(path: Path) -> dict[str, Any]:
    data = yaml.safe_load(path.read_text()) or {}
    if not isinstance(data, dict):
        raise ConfigError(f"{path} must contain a mapping at the top level")
    return data


def load_config(
    campaign: str | None = None,
    overrides_path: Path | None = None,
    config_dir: Path = CONFIG_DIR,
) -> dict[str, Any]:
    cfg = _read_yaml(config_dir / "style.yaml")
    if campaign:
        campaign_path = config_dir / "campaigns" / f"{campaign}.yaml"
        if not campaign_path.exists():
            raise ConfigError(f"Unknown campaign '{campaign}': {campaign_path} not found")
        cfg = deep_merge(cfg, _read_yaml(campaign_path))
        cfg["campaign"] = campaign
    if overrides_path is not None and overrides_path.exists():
        cfg = deep_merge(cfg, _read_yaml(overrides_path))
    return cfg
```

```python
"""Per-video working folders, freshness checks and stage timings."""
from __future__ import annotations

import json
import time
from contextlib import contextmanager
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Iterator

from clipper.env import JOBS_DIR, OUTPUT_DIR


@dataclass(frozen=True)
class Job:
    video_id: str
    root: Path
    out: Path

    @property
    def job_file(self) -> Path:
        return self.root / "job.json"

    @property
    def meta(self) -> Path:
        return self.root / "meta.json"

    @property
    def words(self) -> Path:
        return self.root / "words.json"

    @property
    def sentences_json(self) -> Path:
        return self.root / "sentences.json"

    @property
    def sentences_txt(self) -> Path:
        return self.root / "sentences.txt"

    @property
    def clips(self) -> Path:
        return self.root / "clips.json"

    @property
    def clips_resolved(self) -> Path:
        return self.root / "clips.resolved.json"

    @property
    def overrides(self) -> Path:
        return self.root / "overrides.yaml"

    @property
    def results(self) -> Path:
        return self.root / "results.json"

    @property
    def timings(self) -> Path:
        return self.root / "timings.json"

    @property
    def src_dir(self) -> Path:
        return self.root / "src"

    @property
    def crops_dir(self) -> Path:
        return self.root / "crops"

    @property
    def render_dir(self) -> Path:
        return self.root / "render"

    @property
    def logs_dir(self) -> Path:
        return self.root / "logs"

    @property
    def frames_dir(self) -> Path:
        return self.root / "frames"

    def audio(self) -> Path | None:
        matches = sorted(self.root.glob("audio.*"))
        return matches[0] if matches else None

    def ensure_dirs(self) -> None:
        for d in (self.root, self.out, self.src_dir, self.crops_dir, self.render_dir, self.logs_dir, self.frames_dir):
            d.mkdir(parents=True, exist_ok=True)

    def read_json(self, path: Path) -> Any:
        return json.loads(path.read_text())

    def write_json(self, path: Path, data: Any) -> None:
        path.write_text(json.dumps(data, indent=2, ensure_ascii=False))


def job_for(video_id: str, jobs_dir: Path = JOBS_DIR, output_dir: Path = OUTPUT_DIR) -> Job:
    return Job(video_id=video_id, root=jobs_dir / video_id, out=output_dir / video_id)


def is_fresh(output: Path, inputs: list[Path]) -> bool:
    """True when `output` exists and is at least as new as every input that exists."""
    if not output.exists():
        return False
    out_mtime = output.stat().st_mtime
    return all(out_mtime >= p.stat().st_mtime for p in inputs if p.exists())


@contextmanager
def timed(job: Job, stage: str) -> Iterator[None]:
    start = time.monotonic()
    try:
        yield
    finally:
        data = job.read_json(job.timings) if job.timings.exists() else {}
        data[stage] = round(time.monotonic() - start, 1)
        job.write_json(job.timings, data)
```

```python
"""YouTube downloads through the yt-dlp CLI of this venv."""
from __future__ import annotations

import json
import re
import subprocess
import sys
from pathlib import Path

from clipper.env import ffmpeg_dir
from clipper.jobs import Job

SECTION_PAD = 2.0
_ID_IN_URL = re.compile(r"(?:[?&]v=|/shorts/|/live/|/embed/|youtu\.be/)([A-Za-z0-9_-]{11})")
_BARE_ID = re.compile(r"[A-Za-z0-9_-]{11}")
VIDEO_FORMAT = "bv*[height<=1080][vcodec^=avc1]+ba[ext=m4a]/bv*[height<=1080]+ba/b[height<=1080]"


class FetchError(Exception):
    pass


def extract_video_id(url: str) -> str:
    m = _ID_IN_URL.search(url)
    if m:
        return m.group(1)
    if _BARE_ID.fullmatch(url):
        return url
    raise FetchError(f"Could not find a YouTube video id in: {url}")


def base_cmd(cookies_browser: str | None = None) -> list[str]:
    cmd = [sys.executable, "-m", "yt_dlp", "--no-playlist", "--js-runtimes", "node"]
    d = ffmpeg_dir()
    if d is not None:
        cmd += ["--ffmpeg-location", str(d)]
    if cookies_browser:
        cmd += ["--cookies-from-browser", cookies_browser]
    return cmd


def meta_cmd(url: str, cookies_browser: str | None = None) -> list[str]:
    return base_cmd(cookies_browser) + ["--dump-json", "--skip-download", url]


def audio_cmd(url: str, out_dir: Path, cookies_browser: str | None = None) -> list[str]:
    return base_cmd(cookies_browser) + [
        "-f", "bestaudio[ext=m4a]/bestaudio",
        "-o", str(out_dir / "audio.%(ext)s"),
        url,
    ]


def section_window(start: float, end: float, duration: float | None, pad: float = SECTION_PAD) -> tuple[float, float]:
    s = max(0.0, start - pad)
    e = end + pad
    if duration:
        e = min(e, duration)
    return round(s, 3), round(e, 3)


def section_cmd(url: str, start: float, end: float, out_path: Path, cookies_browser: str | None = None) -> list[str]:
    return base_cmd(cookies_browser) + [
        "-f", VIDEO_FORMAT,
        "--download-sections", f"*{start:.3f}-{end:.3f}",
        "--force-keyframes-at-cuts",
        "--merge-output-format", "mp4",
        "-o", str(out_path),
        url,
    ]


def parse_meta(info: dict) -> dict:
    chapters = [
        {"title": c.get("title", ""), "start": float(c.get("start_time", 0)), "end": float(c.get("end_time", 0))}
        for c in (info.get("chapters") or [])
    ]
    return {
        "video_id": info["id"],
        "title": info.get("title", ""),
        "channel": info.get("channel") or info.get("uploader", ""),
        "channel_handle": info.get("uploader_id", ""),
        "duration": float(info.get("duration") or 0),
        "chapters": chapters,
        "url": info.get("webpage_url") or f"https://www.youtube.com/watch?v={info['id']}",
    }


def run(cmd: list[str], log_path: Path) -> str:
    proc = subprocess.run(cmd, capture_output=True, text=True)
    log_path.parent.mkdir(parents=True, exist_ok=True)
    log_path.write_text(f"$ {' '.join(cmd)}\n\n--- stdout ---\n{proc.stdout}\n--- stderr ---\n{proc.stderr}")
    if proc.returncode != 0:
        tail = "\n".join(proc.stderr.strip().splitlines()[-8:])
        hint = ""
        if "Sign in to confirm" in proc.stderr or "not a bot" in proc.stderr:
            hint = "\nYouTube bot check: ask the user before retrying with --cookies-from-browser."
        raise FetchError(f"yt-dlp failed (exit {proc.returncode}), log: {log_path}\n{tail}{hint}")
    return proc.stdout


def fetch_meta(job: Job, url: str, cookies_browser: str | None = None) -> dict:
    out = run(meta_cmd(url, cookies_browser), job.logs_dir / "fetch_meta.log")
    meta = parse_meta(json.loads(out.strip().splitlines()[-1]))
    job.write_json(job.meta, meta)
    return meta


def fetch_audio(job: Job, url: str, cookies_browser: str | None = None) -> Path:
    run(audio_cmd(url, job.root, cookies_browser), job.logs_dir / "fetch_audio.log")
    audio = job.audio()
    if audio is None:
        raise FetchError("yt-dlp finished but wrote no audio.* file")
    return audio


def fetch_section(job: Job, url: str, clip: dict, duration: float | None, cookies_browser: str | None = None) -> Path:
    out_path = job.src_dir / f"{clip['id']}.mp4"
    s, e = section_window(clip["start"], clip["end"], duration)
    run(section_cmd(url, s, e, out_path, cookies_browser), job.logs_dir / f"fetch_{clip['id']}.log")
    if not out_path.exists():
        raise FetchError(f"Section download for {clip['id']} produced no file")
    return out_path
```

```python
"""Word-level transcription with parakeet-mlx, plus sentence building for Claude."""
from __future__ import annotations

import re
from pathlib import Path

from clipper.jobs import Job

DEFAULT_MODEL = "mlx-community/parakeet-tdt-0.6b-v2"
SENTENCE_END = re.compile(r"[.?!][\"'”’)]*$")


def tokens_to_words(tokens: list[tuple[str, float, float]]) -> list[dict]:
    """Join sub-word tokens into words. A token that starts with whitespace starts a new word."""
    words: list[dict] = []
    for text, start, end in tokens:
        piece = text.strip()
        if not piece:
            continue
        if text[0].isspace() or not words:
            words.append({"i": len(words), "w": piece, "s": round(start, 3), "e": round(end, 3)})
        else:
            words[-1]["w"] += piece
            words[-1]["e"] = round(end, 3)
    return words


def build_sentences(words: list[dict], max_gap: float = 1.2, max_words: int = 50) -> list[dict]:
    sentences: list[dict] = []
    start_i = 0
    for i, word in enumerate(words):
        is_last = i == len(words) - 1
        ends = bool(SENTENCE_END.search(word["w"]))
        long_gap = not is_last and words[i + 1]["s"] - word["e"] > max_gap
        too_long = i - start_i + 1 >= max_words
        if is_last or ends or long_gap or too_long:
            chunk = words[start_i : i + 1]
            sentences.append({
                "id": f"S{len(sentences) + 1:04d}",
                "start_word": start_i,
                "end_word": i,
                "start": chunk[0]["s"],
                "end": chunk[-1]["e"],
                "text": " ".join(x["w"] for x in chunk),
            })
            start_i = i + 1
    return sentences


def format_timestamp(seconds: float) -> str:
    total = int(seconds)
    return f"{total // 3600}:{total % 3600 // 60:02d}:{total % 60:02d}"


def sentences_txt(sentences: list[dict]) -> str:
    return "".join(f"{s['id']} [{format_timestamp(s['start'])}] {s['text']}\n" for s in sentences)


def transcribe_audio(audio_path: Path, model_id: str = DEFAULT_MODEL) -> list[dict]:
    from parakeet_mlx import from_pretrained  # heavy import: keep it lazy

    model = from_pretrained(model_id)
    result = model.transcribe(str(audio_path), chunk_duration=120.0, overlap_duration=15.0)
    tokens: list[tuple[str, float, float]] = []
    for sentence in result.sentences:
        for j, tok in enumerate(sentence.tokens):
            text = tok.text if j else " " + tok.text.lstrip()  # each parakeet sentence starts a new word
            tokens.append((text, tok.start, tok.end))
    return tokens_to_words(tokens)


def run(job: Job, model_id: str = DEFAULT_MODEL) -> list[dict]:
    audio = job.audio()
    if audio is None:
        raise FileNotFoundError(f"No audio file in {job.root}; run `clipper prepare` first")
    words = transcribe_audio(audio, model_id)
    sentences = build_sentences(words)
    job.write_json(job.words, words)
    job.write_json(job.sentences_json, sentences)
    job.sentences_txt.write_text(sentences_txt(sentences))
    return sentences
```

```python
import json
import re
from pathlib import Path

import jsonschema

from clipper.jobs import Job
from clipper.transcribe import SENTENCE_END

SCHEMA_PATH = Path(__file__).parent / "schemas" / "clips.schema.json"
LEAD = 0.08       # seconds of air before the first word
MAX_TAIL = 0.4    # seconds of air after the last word (never into the next word)
PLATFORMS = ("instagram", "tiktok", "youtube", "x")
X_LIMIT = 280
HASHTAG = re.compile(r"#\w+")


class ClipError(Exception):
    pass


def validate_doc(doc: dict) -> None:
    schema = json.loads(SCHEMA_PATH.read_text())
    try:
        jsonschema.validate(doc, schema)
    except jsonschema.ValidationError as exc:
        where = "/".join(str(p) for p in exc.absolute_path)
        raise ClipError(f"clips.json invalid at '{where}': {exc.message}") from exc
    ids = [c["id"] for c in doc["clips"]]
    dupes = sorted({i for i in ids if ids.count(i) > 1})
    if dupes:
        raise ClipError(f"clips.json has duplicate clip ids: {', '.join(dupes)}")


def snap_bounds(words: list[dict], first_i: int, last_i: int) -> tuple[float, float]:
    start = max(0.0, words[first_i]["s"] - LEAD)
    if first_i > 0:
        start = max(start, words[first_i - 1]["e"])
    end = words[last_i]["e"] + MAX_TAIL
    if last_i + 1 < len(words):
        end = min(end, words[last_i + 1]["s"])
    return round(start, 3), round(end, 3)


def overlap_ratio(a: dict, b: dict) -> float:
    inter = max(0.0, min(a["end"], b["end"]) - max(a["start"], b["start"]))
    shorter = min(a["end"] - a["start"], b["end"] - b["start"])
    return inter / shorter if shorter > 0 else 0.0


def compose_post(text: str, cfg: dict, platform: str) -> str:
    found = HASHTAG.findall(text)
    body = HASHTAG.sub("", text)
    body = "\n".join(re.sub(r"[ \t]{2,}", " ", line).strip() for line in body.splitlines()).strip()
    required = [t if t.startswith("#") else f"#{t}" for t in cfg.get("required_tags", [])]
    tags: list[str] = []
    for tag in required + found:
        if tag.lower() not in {t.lower() for t in tags}:
            tags.append(tag)
    tags = tags[: max(cfg.get("max_hashtags", 5), len(required))]
    tail_lines: list[str] = []
    seen = body.lower()
    for extra in (cfg.get("required_text", ""), cfg.get("creator_tag", "")):
        if extra and extra.lower() not in seen:
            tail_lines.append(extra)
            seen += "\n" + extra.lower()
    if tags:
        tail_lines.append(" ".join(tags))
    tail = "\n".join(tail_lines)
    if platform == "x" and len(body) + len(tail) + 1 > X_LIMIT:
        room = X_LIMIT - len(tail) - 1
        if room < 2:
            raise ClipError(f"required text and tags alone exceed X's {X_LIMIT} characters")
        body = body[: room - 1].rstrip() + "…"
    return "\n".join(part for part in (body, tail) if part)


def resolve_all(doc: dict, sentences: list[dict], words: list[dict], cfg: dict) -> dict:
    validate_doc(doc)
    by_id = {s["id"]: s for s in sentences}
    length = cfg["length"]
    max_overlap = cfg.get("max_overlap", 0.5)
    accepted: list[dict] = []
    rejected: list[dict] = []
    for clip in sorted(doc["clips"], key=lambda c: c["score"], reverse=True):
        try:
            first, last = by_id.get(clip["start_sentence"]), by_id.get(clip["end_sentence"])
            if first is None or last is None:
                raise ClipError("unknown sentence id")
            if first["start_word"] > last["end_word"]:
                raise ClipError("end_sentence comes before start_sentence")
            if clip["score"] < cfg["min_score"]:
                raise ClipError(f"score {clip['score']} below min_score {cfg['min_score']}")
            start, end = snap_bounds(words, first["start_word"], last["end_word"])
            duration = round(end - start, 3)
            if not length["min"] <= duration <= length["max"]:
                raise ClipError(f"duration {duration:.1f}s outside {length['min']}-{length['max']}s")
            resolved = {**clip, "start": start, "end": end, "duration": duration,
                        "first_word": first["start_word"], "last_word": last["end_word"],
                        "post": {p: compose_post(clip["post"][p], cfg, p) for p in PLATFORMS}}
            for other in accepted:
                if overlap_ratio(resolved, other) > max_overlap:
                    raise ClipError(f"overlaps {other['id']} by more than {max_overlap:.0%}")
            if len(accepted) >= cfg["max_clips"]:
                raise ClipError(f"beyond max_clips ({cfg['max_clips']})")
            accepted.append(resolved)
        except ClipError as exc:
            rejected.append({"id": clip["id"], "title": clip["title"], "reason": str(exc)})
    return {"video_id": doc["video_id"], "clips": accepted, "rejected": rejected}


def clip_words(words: list[dict], clip: dict) -> list[dict]:
    off = clip["start"]
    return [{**w, "s": round(w["s"] - off, 3), "e": round(w["e"] - off, 3)}
            for w in words[clip["first_word"] : clip["last_word"] + 1]]


def sentence_end_times(cwords: list[dict]) -> list[float]:
    return [w["e"] for w in cwords if SENTENCE_END.search(w["w"])]


def run(job: Job, cfg: dict) -> dict:
    result = resolve_all(job.read_json(job.clips), job.read_json(job.sentences_json), job.read_json(job.words), cfg)
    job.write_json(job.clips_resolved, result)
    return result
```

```python
"""Pure reframing logic: face samples -> tracks -> per-shot layout segments with crop boxes."""
from __future__ import annotations

import math
import statistics
from dataclasses import dataclass, field

SAMPLE_FPS = 5.0          # face samples per second
WINDOW = 1.0              # seconds per speaking-activity window
DOMINANCE = 1.4           # active speaker's mouth variance must beat the other's by this factor
SILENT_VAR = 0.0004       # mouth-ratio variance below this means "not talking"
MIN_HOLD = 1.5            # never show a speaker for less than this many seconds
SPLIT_MIN = 3.0           # back-and-forth must last this long to use the split layout
SPLIT_SIZE_RATIO = 0.65   # both faces must be similar in size for split
SNAP_TOL = 0.75           # move a speaker switch to a sentence end within this distance
MIN_TRACK_PRESENCE = 0.3  # a face track must appear in this share of a shot's samples
MIN_FACE_AREA_RATIO = 0.10
TRACK_DIST_FRAC = 0.15    # max centre jump between samples, as a share of frame width
MIN_SHOT = 0.8

Box = tuple[float, float, float, float]


@dataclass
class Face:
    t: float
    box: Box    # x, y, w, h in source pixels
    mar: float  # mouth aspect ratio: inner-lip gap / mouth width

    @property
    def center(self) -> tuple[float, float]:
        x, y, w, h = self.box
        return x + w / 2, y + h / 2

    @property
    def area(self) -> float:
        return self.box[2] * self.box[3]


@dataclass
class Track:
    faces: list[Face] = field(default_factory=list)

    def median_box(self) -> Box:
        return tuple(statistics.median(f.box[k] for f in self.faces) for k in range(4))  # type: ignore[return-value]

    def median_area(self) -> float:
        _, _, w, h = self.median_box()
        return w * h

    def mar_variance(self, t0: float, t1: float) -> float:
        vals = [f.mar for f in self.faces if t0 <= f.t < t1]
        return statistics.pvariance(vals) if len(vals) >= 2 else 0.0


def even(v: float) -> int:
    n = int(v)
    return n - (n % 2)


def _clamp(v: float, lo: float, hi: float) -> float:
    return max(lo, min(v, hi))


def fill_box(center_x: float, src_w: int, src_h: int) -> list[int]:
    w = even(min(src_w, src_h * 9 / 16))
    h = even(min(src_h, w * 16 / 9))
    x = even(_clamp(center_x - w / 2, 0, src_w - w))
    y = even((src_h - h) / 2)
    return [x, y, w, h]


def split_box(face_box: Box, src_w: int, src_h: int) -> list[int]:
    fx, fy, fw, fh = face_box
    h = min(src_h, fh * 2.6)
    w = h * 9 / 8
    if w > src_w:
        w, h = src_w, src_w * 8 / 9
    w, h = even(w), even(h)
    cx, cy = fx + fw / 2, fy + fh / 2
    x = even(_clamp(cx - w / 2, 0, src_w - w))
    y = even(_clamp(cy - h * 0.45, 0, src_h - h))
    return [x, y, w, h]


def zoom_box(base: list[int], center: tuple[float, float] | None, scale: float) -> list[int]:
    bx, by, bw, bh = base
    w, h = even(bw / scale), even(bh / scale)
    cx, cy = center if center else (bx + bw / 2, by + bh / 2)
    x = even(_clamp(cx - w / 2, bx, bx + bw - w))
    y = even(_clamp(cy - h * 0.4, by, by + bh - h))
    return [x, y, w, h]


def assign_tracks(samples: list[list[Face]], src_w: int) -> list[Track]:
    tracks: list[Track] = []
    max_dist = TRACK_DIST_FRAC * src_w
    for faces in samples:
        used: set[int] = set()
        for face in sorted(faces, key=lambda f: -f.area):
            best, best_d = None, max_dist
            for idx, track in enumerate(tracks):
                if idx in used:
                    continue
                d = math.dist(track.faces[-1].center, face.center)
                if d < best_d:
                    best, best_d = idx, d
            if best is None:
                tracks.append(Track([face]))
                used.add(len(tracks) - 1)
            else:
                tracks[best].faces.append(face)
                used.add(best)
    kept = [t for t in tracks if len(t.faces) >= MIN_TRACK_PRESENCE * max(len(samples), 1)]
    if kept:
        largest = max(t.median_area() for t in kept)
        kept = [t for t in kept if t.median_area() >= MIN_FACE_AREA_RATIO * largest]
    return sorted(kept, key=lambda t: t.median_box()[0])


def _window_labels(pair: list[Track], t0: float, t1: float) -> list[tuple[float, float, str]]:
    labels = []
    t = t0
    while t < t1 - 1e-6:
        e = min(t + WINDOW, t1)
        va, vb = pair[0].mar_variance(t, e), pair[1].mar_variance(t, e)
        a_on, b_on = va > SILENT_VAR, vb > SILENT_VAR
        if a_on and va >= DOMINANCE * vb:
            label = "A"
        elif b_on and vb >= DOMINANCE * va:
            label = "B"
        elif a_on and b_on:
            label = "both"
        else:
            label = "none"
        labels.append((t, e, label))
        t = e
    return labels


def _runs(labels: list[tuple[float, float, str]]) -> list[tuple[float, float, str]]:
    runs: list[tuple[float, float, str]] = []
    for s, e, label in labels:
        if runs and runs[-1][2] == label:
            runs[-1] = (runs[-1][0], e, label)
        else:
            runs.append((s, e, label))
    return runs


def _snap_switches(plan: list[list], sentence_ends: list[float]) -> list[list]:
    for i in range(len(plan) - 1):
        b = plan[i][1]
        near = [t for t in sentence_ends if abs(t - b) <= SNAP_TOL and plan[i][0] < t < plan[i + 1][1]]
        if near:
            nb = min(near, key=lambda t: abs(t - b))
            plan[i][1] = plan[i + 1][0] = nb
    return plan


def _enforce_min_hold(plan: list[list]) -> list[list]:
    out: list[list] = []
    for s, e, who in plan:
        if out and (e - s < MIN_HOLD or out[-1][2] == who):
            out[-1][1] = e
        else:
            out.append([s, e, who])
    if len(out) > 1 and out[0][1] - out[0][0] < MIN_HOLD:
        out[1][0] = out[0][0]
        out.pop(0)
    return out


def _segment(s: float, e: float, who: str, pair: list[Track], src_w: int, src_h: int) -> dict:
    seg: dict = {"start": round(s, 3), "end": round(e, 3), "layout": "fill", "boxes": [], "face": None}
    if who == "fit":
        seg["layout"] = "fit"
    elif who == "split":
        seg["layout"] = "split"
        seg["boxes"] = [split_box(t.median_box(), src_w, src_h) for t in pair]
    else:
        x, y, w, h = (pair[0] if who == "A" else pair[1]).median_box()
        seg["boxes"] = [fill_box(x + w / 2, src_w, src_h)]
        seg["face"] = [round(x), round(y), round(w), round(h)]
    return seg


def plan_shot(t0: float, t1: float, tracks: list[Track], src_w: int, src_h: int,
              sentence_ends: list[float]) -> list[dict]:
    if not tracks:
        return [_segment(t0, t1, "fit", [], src_w, src_h)]
    if len(tracks) == 1:
        return [_segment(t0, t1, "A", tracks, src_w, src_h)]
    pair = sorted(sorted(tracks, key=lambda t: -t.median_area())[:2], key=lambda t: t.median_box()[0])
    areas = [t.median_area() for t in pair]
    can_split = min(areas) >= SPLIT_SIZE_RATIO * max(areas)
    current = "A" if pair[0].mar_variance(t0, t1) >= pair[1].mar_variance(t0, t1) else "B"
    plan: list[list] = []
    for s, e, label in _runs(_window_labels(pair, t0, t1)):
        if label == "both" and can_split and e - s >= SPLIT_MIN:
            who = "split"
        elif label in ("A", "B"):
            who = label
        else:
            who = current
        if plan and plan[-1][2] == who:
            plan[-1][1] = e
        else:
            plan.append([s, e, who])
        current = who
    plan = _enforce_min_hold(_snap_switches(plan, sentence_ends))
    return [_segment(s, e, who, pair, src_w, src_h) for s, e, who in plan]


def merge_short_shots(shots: list[tuple[float, float]], min_len: float = MIN_SHOT) -> list[tuple[float, float]]:
    out: list[tuple[float, float]] = []
    for s, e in shots:
        if out and e - s < min_len:
            out[-1] = (out[-1][0], e)
        else:
            out.append((s, e))
    if len(out) > 1 and out[0][1] - out[0][0] < min_len:
        out[1] = (out[0][0], out[1][1])
        out.pop(0)
    return out


def plan_clip(shots: list[tuple[float, float]], samples: list[tuple[float, list[Face]]],
              src_w: int, src_h: int, sentence_ends: list[float]) -> list[dict]:
    """shots and samples are in clip time (0 = first frame of the finished clip)."""
    segments: list[dict] = []
    for s, e in shots:
        in_shot = [faces for t, faces in samples if s <= t < e]
        tracks = assign_tracks(in_shot, src_w)
        segments += plan_shot(s, e, tracks, src_w, src_h, [t for t in sentence_ends if s < t < e])
    return segments
```

```python
"""Reframe stage I/O: shot cuts (PySceneDetect) + face samples (MediaPipe) -> crops/<clip>.json."""
from __future__ import annotations

import math
from pathlib import Path

import cv2
import numpy as np

from clipper.clips import clip_words, sentence_end_times
from clipper.env import FACE_MODEL_PATH
from clipper.fetch import section_window
from clipper.jobs import Job
from clipper.layout import SAMPLE_FPS, Face, merge_short_shots, plan_clip

SHOT_THRESHOLD = 27.0
ANALYSIS_WIDTH = 960
LIP_TOP, LIP_BOTTOM, MOUTH_LEFT, MOUTH_RIGHT = 13, 14, 61, 291


def probe(video: Path) -> tuple[int, int, float, float]:
    cap = cv2.VideoCapture(str(video))
    if not cap.isOpened():
        raise RuntimeError(f"OpenCV cannot open {video}")
    w = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
    h = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
    fps = cap.get(cv2.CAP_PROP_FPS) or 30.0
    frames = cap.get(cv2.CAP_PROP_FRAME_COUNT) or 0.0
    cap.release()
    return w, h, fps, frames / fps


def detect_shots(video: Path) -> list[tuple[float, float]]:
    from scenedetect import ContentDetector, detect

    scenes = detect(str(video), ContentDetector(threshold=SHOT_THRESHOLD))
    return [(start.get_seconds(), end.get_seconds()) for start, end in scenes]


def mouth_ratio(pts: list[tuple[float, float]]) -> float:
    width = math.dist(pts[MOUTH_LEFT], pts[MOUTH_RIGHT])
    return math.dist(pts[LIP_TOP], pts[LIP_BOTTOM]) / width if width > 0 else 0.0


def sample_faces(video: Path, src_w: int, src_h: int, fps: float, t_offset: float = 0.0,
                 model_path: Path = FACE_MODEL_PATH) -> list[tuple[float, list[Face]]]:
    """Run FaceLandmarker ~SAMPLE_FPS times per second. Times are returned as (section time - t_offset)."""
    import mediapipe as mp
    from mediapipe.tasks import python as mp_python
    from mediapipe.tasks.python import vision

    options = vision.FaceLandmarkerOptions(
        base_options=mp_python.BaseOptions(model_asset_path=str(model_path)),
        running_mode=vision.RunningMode.VIDEO,
        num_faces=4,
    )
    step = max(1, round(fps / SAMPLE_FPS))
    samples: list[tuple[float, list[Face]]] = []
    cap = cv2.VideoCapture(str(video))
    with vision.FaceLandmarker.create_from_options(options) as landmarker:
        idx = 0
        while cap.grab():
            if idx % step == 0:
                ok, frame = cap.retrieve()
                if not ok:
                    break
                t_src = idx / fps
                scale = ANALYSIS_WIDTH / frame.shape[1]
                if scale < 1:
                    frame = cv2.resize(frame, (ANALYSIS_WIDTH, round(frame.shape[0] * scale)))
                rgb = np.ascontiguousarray(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))
                image = mp.Image(image_format=mp.ImageFormat.SRGB, data=rgb)
                result = landmarker.detect_for_video(image, int(t_src * 1000))
                t = round(t_src - t_offset, 3)
                faces = []
                for landmarks in result.face_landmarks:
                    pts = [(lm.x * src_w, lm.y * src_h) for lm in landmarks]
                    xs, ys = [p[0] for p in pts], [p[1] for p in pts]
                    box = (min(xs), min(ys), max(xs) - min(xs), max(ys) - min(ys))
                    faces.append(Face(t, box, mouth_ratio(pts)))
                samples.append((t, faces))
            idx += 1
    cap.release()
    return samples


def to_clip_shots(shots: list[tuple[float, float]], offset: float, duration: float) -> list[tuple[float, float]]:
    clip_shots = [(max(0.0, s - offset), min(duration, e - offset)) for s, e in shots]
    clip_shots = [(round(s, 3), round(e, 3)) for s, e in clip_shots if e - s > 0.01]
    if not clip_shots:
        return [(0.0, duration)]
    clip_shots[0] = (0.0, clip_shots[0][1])
    clip_shots[-1] = (clip_shots[-1][0], duration)
    return merge_short_shots(clip_shots)


def run(job: Job, clip: dict, words: list[dict], meta_duration: float | None) -> Path:
    src = job.src_dir / f"{clip['id']}.mp4"
    section_start, _ = section_window(clip["start"], clip["end"], meta_duration)
    offset = round(clip["start"] - section_start, 3)
    src_w, src_h, fps, _ = probe(src)
    shots = to_clip_shots(detect_shots(src), offset, clip["duration"])
    samples = sample_faces(src, src_w, src_h, fps, t_offset=offset)
    ends = sentence_end_times(clip_words(words, clip))
    segments = plan_clip(shots, samples, src_w, src_h, ends)
    out = job.crops_dir / f"{clip['id']}.json"
    job.write_json(out, {"clip_id": clip["id"], "src_w": src_w, "src_h": src_h, "offset": offset, "segments": segments})
    return out
```

```python
"""Group words into short captions and write an ASS subtitle file for libass."""
from __future__ import annotations

import re

import pysubs2

from clipper.transcribe import SENTENCE_END

EDGE_PUNCT = re.compile(r"^[^\w$#@]+|[^\w%]+$")
MAX_GAP = 0.6   # a pause longer than this starts a new caption group
LINGER = 0.3    # keep a group on screen this long after its last word (unless the next starts sooner)
POP = r"\fscx85\fscy85\t(0,80,\fscx100\fscy100)"


def clean(word: str) -> str:
    return EDGE_PUNCT.sub("", word)


def ass_color(hex_rgb: str) -> str:
    h = hex_rgb.lstrip("#").upper()
    return f"&H{h[4:6]}{h[2:4]}{h[0:2]}&"


def _ssa_color(hex_rgb: str, alpha: int = 0) -> pysubs2.Color:
    h = hex_rgb.lstrip("#")
    return pysubs2.Color(int(h[0:2], 16), int(h[2:4], 16), int(h[4:6], 16), alpha)


def group_words(words: list[dict], max_words: int = 3, max_chars: int = 15, uppercase: bool = True) -> list[dict]:
    groups: list[list[dict]] = []
    for w in words:
        text = clean(w["w"])
        if not text:
            continue
        item = {"text": text.upper() if uppercase else text, "key": text.lower(), "s": w["s"], "e": w["e"], "raw": w["w"]}
        if groups:
            cur = groups[-1]
            prev = cur[-1]
            joined_len = sum(len(x["text"]) for x in cur) + len(cur) + len(item["text"])
            if (len(cur) < max_words and joined_len <= max_chars
                    and item["s"] - prev["e"] <= MAX_GAP and not SENTENCE_END.search(prev["raw"])):
                cur.append(item)
                continue
        groups.append([item])
    out = []
    for i, g in enumerate(groups):
        end = g[-1]["e"] + LINGER
        if i + 1 < len(groups):
            end = min(end, groups[i + 1][0]["s"])
        end = max(end, g[0]["s"] + 0.05)
        out.append({"start": g[0]["s"], "end": round(end, 3), "words": g})
    return out


def _layout_at(segments: list[dict], t: float) -> str:
    for seg in segments:
        if seg["start"] <= t < seg["end"]:
            return seg["layout"]
    return segments[-1]["layout"] if segments else "fill"


def _ms(t: float) -> int:
    return max(0, int(round(t * 1000)))


def build_ass(groups: list[dict], cfg: dict, segments: list[dict], hook_text: str | None,
              emphasis: set[str]) -> pysubs2.SSAFile:
    c, hk = cfg["captions"], cfg["hook_text"]
    subs = pysubs2.SSAFile()
    subs.info.update({"PlayResX": "1080", "PlayResY": "1920", "WrapStyle": "0", "ScaledBorderAndShadow": "yes"})
    subs.styles["Cap"] = pysubs2.SSAStyle(
        fontname=c["font"], fontsize=c["size"], primarycolor=_ssa_color(c["color"]),
        outlinecolor=_ssa_color("#000000"), backcolor=_ssa_color("#000000", 120),
        bold=False, outline=c["outline"], shadow=c["shadow"],
        alignment=pysubs2.Alignment.MIDDLE_CENTER, marginl=0, marginr=0, marginv=0)
    # BorderStyle 3 = opaque box; libass/VSFilter differ on which colour fills it, so set both to white.
    subs.styles["Hook"] = pysubs2.SSAStyle(
        fontname=c["font"], fontsize=hk["size"], primarycolor=_ssa_color("#000000"),
        outlinecolor=_ssa_color("#FFFFFF"), backcolor=_ssa_color("#FFFFFF"),
        bold=False, borderstyle=3, outline=14, shadow=0,
        alignment=pysubs2.Alignment.TOP_CENTER, marginl=90, marginr=140, marginv=hk["margin_top"])
    if hook_text and hk["enabled"]:
        subs.append(pysubs2.SSAEvent(start=0, end=_ms(hk["duration"]), style="Hook", text=hook_text.upper()))
    hl, base = ass_color(c["highlight_color"]), ass_color(c["color"])
    for g in groups:
        y = c["split_y"] if _layout_at(segments, g["start"]) == "split" else c["y"]
        n = len(g["words"])
        for i, active in enumerate(g["words"]):
            s = g["start"] if i == 0 else active["s"]
            e = g["words"][i + 1]["s"] if i + 1 < n else g["end"]
            if e <= s:
                continue
            parts = [f"{{\\c{hl if (j == i or w['key'] in emphasis) else base}}}{w['text']}"
                     for j, w in enumerate(g["words"])]
            head = f"{{\\an5\\pos({c['x']},{y}){POP if i == 0 else ''}}}"
            subs.append(pysubs2.SSAEvent(start=_ms(s), end=_ms(e), style="Cap", text=head + " ".join(parts)))
    return subs
```

```python
"""Decide when hard-cut punch-in zooms happen. Pure functions."""
from __future__ import annotations


def toggle_times(anchors: list[float], duration: float, min_gap: float, max_gap: float) -> list[float]:
    """Times where the zoom state flips (in, out, in, ...). Prefer anchors (sentence ends, emphasis words)."""
    toggles: list[float] = []
    last = 0.0
    pending = sorted(a for a in anchors if 0 < a < duration - 1.0)
    while True:
        candidates = [a for a in pending if min_gap <= a - last <= max_gap]
        if candidates:
            t = candidates[0]
        elif last + max_gap < duration - 1.0:
            t = last + max_gap
        else:
            break
        toggles.append(round(t, 3))
        last = t
    return toggles


def plan_zooms(segments: list[dict], anchors: list[float], duration: float, cfg: dict) -> list[dict]:
    zc = cfg["zoom"]
    if not zc["enabled"]:
        return []
    toggles = toggle_times(anchors, duration, zc["min_gap"], zc["max_gap"])
    zooms = []
    for i in range(0, len(toggles), 2):
        start = toggles[i]
        end = toggles[i + 1] if i + 1 < len(toggles) else duration
        seg = next((s for s in segments if s["start"] <= start < s["end"]), None)
        if seg is None or seg["layout"] != "fill":
            continue
        end = min(end, seg["end"])
        if end - start >= 0.5:
            zooms.append({"start": start, "end": round(end, 3), "scale": zc["scale"]})
    return zooms
```

```python
"""One ffmpeg pass per clip: crop/zoom, captions, SFX, loudness, encode."""
from __future__ import annotations

import json
import os
import re
import subprocess
from pathlib import Path

from clipper.captions import build_ass, clean, group_words
from clipper.clips import clip_words, sentence_end_times
from clipper.env import FONTS_DIR, WHOOSH_PATH, ffmpeg_bin
from clipper.fetch import section_window
from clipper.jobs import Job
from clipper.layout import zoom_box
from clipper.zooms import plan_zooms

OUT_W, OUT_H, HALF_H = 1080, 1920, 960
LOUDNORM = "loudnorm=I=-14:TP=-1:LRA=11"
WHOOSH_LEAD = 0.15  # start the whoosh slightly before the cut
STEREO_48K = "aresample=48000,aformat=sample_rates=48000:channel_layouts=stereo"


class RenderError(Exception):
    pass


def split_pieces(segments: list[dict], zooms: list[dict]) -> list[dict]:
    """Cut segments at zoom edges so every piece has exactly one crop."""
    pieces = []
    for seg in segments:
        cuts = {seg["start"], seg["end"]}
        for z in zooms:
            cuts.update(t for t in (z["start"], z["end"]) if seg["start"] < t < seg["end"])
        edges = sorted(cuts)
        for a, b in zip(edges, edges[1:]):
            mid = (a + b) / 2
            zoom = next((z for z in zooms if z["start"] <= mid < z["end"]), None)
            boxes = seg["boxes"]
            if zoom and seg["layout"] == "fill":
                face = seg.get("face")
                center = (face[0] + face[2] / 2, face[1] + face[3] / 2) if face else None
                boxes = [zoom_box(boxes[0], center, zoom["scale"])]
            pieces.append({"start": a, "end": b, "layout": seg["layout"], "boxes": boxes})
    return pieces


def video_graph(pieces: list[dict], fps: int, ass_name: str | None) -> str:
    n = len(pieces)
    chains = [f"[0:v]split={n}" + "".join(f"[v{i}]" for i in range(n))]
    for i, p in enumerate(pieces):
        head = f"[v{i}]trim=start={p['start']:.3f}:end={p['end']:.3f},setpts=PTS-STARTPTS"
        if p["layout"] == "fill":
            x, y, w, h = p["boxes"][0]
            chains.append(f"{head},crop={w}:{h}:{x}:{y},scale={OUT_W}:{OUT_H}:flags=lanczos,setsar=1[p{i}]")
        elif p["layout"] == "split":
            (x1, y1, w1, h1), (x2, y2, w2, h2) = p["boxes"]
            chains += [
                f"{head},split[a{i}][b{i}]",
                f"[a{i}]crop={w1}:{h1}:{x1}:{y1},scale={OUT_W}:{HALF_H}:flags=lanczos[t{i}]",
                f"[b{i}]crop={w2}:{h2}:{x2}:{y2},scale={OUT_W}:{HALF_H}:flags=lanczos[u{i}]",
                f"[t{i}][u{i}]vstack,setsar=1[p{i}]",
            ]
        else:  # fit: whole frame over a blurred, filled background
            chains += [
                f"{head},split[a{i}][b{i}]",
                f"[a{i}]scale=270:480:force_original_aspect_ratio=increase,crop=270:480,boxblur=10:2,"
                f"scale={OUT_W}:{OUT_H}[g{i}]",
                f"[b{i}]scale={OUT_W}:-2[f{i}]",
                f"[g{i}][f{i}]overlay=(W-w)/2:(H-h)/2,setsar=1[p{i}]",
            ]
    tail = "".join(f"[p{i}]" for i in range(n)) + f"concat=n={n}:v=1:a=0,fps={fps}"
    if ass_name:
        tail += f",ass={ass_name}:fontsdir=fonts"
    chains.append(tail + ",format=yuv420p[vout]")
    return ";".join(chains)


def audio_graph(sfx_times: list[float], gain_db: float, loudnorm: str) -> str:
    if not sfx_times:
        return f"[0:a]{STEREO_48K},{loudnorm},aresample=48000[aout]"
    n = len(sfx_times)
    chains = [f"[0:a]{STEREO_48K}[sp]",
              f"[1:a]{STEREO_48K},volume={gain_db}dB,asplit={n}" + "".join(f"[s{i}]" for i in range(n))]
    chains += [f"[s{i}]adelay=delays={int(round(t * 1000))}:all=1[d{i}]" for i, t in enumerate(sfx_times)]
    chains.append("[sp]" + "".join(f"[d{i}]" for i in range(n))
                  + f"amix=inputs={n + 1}:duration=first:normalize=0,{loudnorm},aresample=48000[aout]")
    return ";".join(chains)


def parse_loudnorm(stderr: str) -> dict:
    blocks = re.findall(r"\{[^{}]*\"input_i\"[^{}]*\}", stderr)
    if not blocks:
        raise RenderError("loudnorm measurement not found in ffmpeg output")
    return json.loads(blocks[-1])


def loudnorm_pass2(m: dict) -> str:
    keys = ("input_i", "input_tp", "input_lra", "input_thresh", "target_offset")
    if any("inf" in str(m[k]) for k in keys):  # silent audio: fall back to single-pass
        return LOUDNORM
    return (f"{LOUDNORM}:measured_I={m['input_i']}:measured_TP={m['input_tp']}:measured_LRA={m['input_lra']}"
            f":measured_thresh={m['input_thresh']}:offset={m['target_offset']}:linear=true")


def encode_args(cfg: dict) -> list[str]:
    r = cfg["render"]
    if r["fast"]:
        video = ["-c:v", "h264_videotoolbox", "-q:v", "60", "-profile:v", "high"]
    else:
        video = ["-c:v", "libx264", "-preset", "medium", "-crf", str(r["crf"]), "-profile:v", "high"]
    return video + ["-pix_fmt", "yuv420p", "-r", str(r["fps"]), "-c:a", "aac", "-b:a", "192k", "-ar", "48000",
                    "-movflags", "+faststart"]


def _input_args(src: Path, offset: float, duration: float, use_sfx: bool) -> list[str]:
    args = ["-ss", f"{offset:.3f}", "-t", f"{duration:.3f}", "-i", str(src)]
    if use_sfx:
        args += ["-i", str(WHOOSH_PATH)]
    return args


def _run(cmd: list[str], cwd: Path, log: Path) -> subprocess.CompletedProcess:
    proc = subprocess.run(cmd, cwd=cwd, capture_output=True, text=True)
    log.parent.mkdir(parents=True, exist_ok=True)
    log.write_text(f"$ {' '.join(cmd)}\n\n{proc.stderr}")
    if proc.returncode != 0:
        tail = "\n".join(proc.stderr.strip().splitlines()[-10:])
        raise RenderError(f"ffmpeg failed (exit {proc.returncode}), log: {log}\n{tail}")
    return proc


def _link_fonts(render_dir: Path) -> None:
    link = render_dir / "fonts"
    if not link.exists():
        os.symlink(FONTS_DIR, link)


def render_clip(job: Job, clip: dict, cfg: dict, words: list[dict], meta_duration: float | None) -> Path:
    cid = clip["id"]
    segments = job.read_json(job.crops_dir / f"{cid}.json")["segments"]
    duration = clip["duration"]
    section_start, _ = section_window(clip["start"], clip["end"], meta_duration)
    offset = round(clip["start"] - section_start, 3)
    src = job.src_dir / f"{cid}.mp4"

    cw = clip_words(words, clip)
    emphasis = {e.lower() for e in clip.get("emphasis_words", [])}
    anchors = sentence_end_times(cw) + [w["e"] for w in cw if clean(w["w"]).lower() in emphasis]
    zooms = plan_zooms(segments, anchors, duration, cfg)
    pieces = split_pieces(segments, zooms)

    cap = cfg["captions"]
    groups = group_words(cw, cap["max_words"], cap["max_chars"], cap["uppercase"])
    ass_name = f"{cid}.ass"
    build_ass(groups, cfg, segments, clip.get("hook_text"), emphasis).save(str(job.render_dir / ass_name))
    _link_fonts(job.render_dir)

    use_sfx = cfg["sfx"]["enabled"] and bool(zooms) and WHOOSH_PATH.exists()
    sfx_times = [max(0.0, z["start"] - WHOOSH_LEAD) for z in zooms] if use_sfx else []
    inputs = _input_args(src, offset, duration, use_sfx)
    gain = cfg["sfx"]["gain_db"]

    measure_cmd = [ffmpeg_bin(), "-hide_banner", "-nostats", *inputs,
                   "-filter_complex", audio_graph(sfx_times, gain, f"{LOUDNORM}:print_format=json"),
                   "-map", "[aout]", "-f", "null", "-"]
    measured = parse_loudnorm(_run(measure_cmd, job.render_dir, job.logs_dir / f"{cid}_loudnorm.log").stderr)

    out = job.out / f"{cid}.mp4"
    graph = video_graph(pieces, cfg["render"]["fps"], ass_name) + ";" + audio_graph(sfx_times, gain, loudnorm_pass2(measured))
    cmd = [ffmpeg_bin(), "-hide_banner", "-y", *inputs, "-filter_complex", graph,
           "-map", "[vout]", "-map", "[aout]", *encode_args(cfg), "-t", f"{duration:.3f}", str(out)]
    _run(cmd, job.render_dir, job.logs_dir / f"{cid}_render.log")
    return out
```

```python
"""Post captions, run summary, QA frames and cleanup."""
from __future__ import annotations

import shutil
import subprocess
from pathlib import Path

from clipper.env import ffmpeg_bin
from clipper.jobs import Job
from clipper.transcribe import format_timestamp

PLATFORM_LABELS = {"instagram": "Instagram Reels", "tiktok": "TikTok", "youtube": "YouTube Shorts", "x": "X"}


def frame_times(duration: float) -> list[float]:
    """First frame (hook visible), then 25%, 60% and 90% through the clip."""
    return [min(0.5, duration / 2)] + [round(duration * p, 2) for p in (0.25, 0.6, 0.9)]


def extract_frames(video: Path, duration: float, out_dir: Path) -> list[Path]:
    out_dir.mkdir(parents=True, exist_ok=True)
    paths = []
    for k, t in enumerate(frame_times(duration)):
        path = out_dir / f"{video.stem}_{k}.jpg"
        subprocess.run([ffmpeg_bin(), "-hide_banner", "-loglevel", "error", "-y", "-ss", f"{t:.2f}", "-i", str(video),
                        "-frames:v", "1", "-vf", "scale=540:-2", str(path)], check=True)
        paths.append(path)
    return paths


def post_markdown(clip: dict) -> str:
    lines = [
        f"# {clip['title']}", "",
        f"- **File:** {clip['id']}.mp4",
        f"- **Score:** {clip['score']}/10 ({clip['reason']})",
        f"- **Hook text:** {clip['hook_text']}",
        f"- **Source:** {format_timestamp(clip['start'])} to {format_timestamp(clip['end'])} ({clip['duration']:.0f}s)",
        "",
    ]
    for key, label in PLATFORM_LABELS.items():
        lines += [f"## {label}", "", "```", clip["post"][key], "```", ""]
    return "\n".join(lines)


def summary_markdown(meta: dict, resolved: dict, results: dict[str, str | None], timings: dict) -> str:
    lines = [f"# {meta['title']}", "", f"Channel: {meta['channel']}  ", f"Source: {meta['url']}", "",
             "## Clips", "", "| Clip | Score | Length | Title | Status | Source time |", "|---|---|---|---|---|---|"]
    for clip in resolved["clips"]:
        if clip["id"] not in results:
            continue
        err = results[clip["id"]]
        status = "ready" if err is None else f"FAILED: {err}"
        link = f"{meta['url']}&t={int(clip['start'])}s" if "watch?v=" in meta["url"] else meta["url"]
        title = clip["title"].replace("|", "/")
        lines.append(f"| {clip['id']} | {clip['score']} | {clip['duration']:.0f}s | {title} | {status} | "
                     f"[{format_timestamp(clip['start'])}]({link}) |")
    if resolved.get("rejected"):
        lines += ["", "## Not used", ""] + [f"- {r['id']} ({r['title']}): {r['reason']}" for r in resolved["rejected"]]
    if timings:
        lines += ["", "## Stage timings (seconds)", ""] + [f"- {k}: {v}" for k, v in timings.items()]
    return "\n".join(lines) + "\n"


def cleanup(job: Job) -> list[Path]:
    removed: list[Path] = []
    audio = job.audio()
    if audio is not None:
        audio.unlink()
        removed.append(audio)
    if job.src_dir.exists():
        shutil.rmtree(job.src_dir)
        removed.append(job.src_dir)
    return removed
```

```python
"""Environment preflight: binaries, Python packages, assets, disk space."""
from __future__ import annotations

import importlib.metadata
import importlib.util
import re
import shutil
import subprocess
import sys
from dataclasses import dataclass
from pathlib import Path
from typing import Callable

from clipper.env import FACE_MODEL_PATH, FFMPEG_FULL_DIR, FONT_PATH, PROJECT_ROOT, WHOOSH_PATH, ffmpeg_bin, ffmpeg_dir

MIN_FREE_GB = 5.0
SETUP_ASSETS = "bash scripts/setup_assets.sh"


@dataclass
class Check:
    name: str
    ok: bool
    detail: str
    fix: str = ""


def check_disk(path: Path, usage: Callable = shutil.disk_usage) -> Check:
    free_gb = usage(path).free / 1024**3
    return Check("disk space", free_gb >= MIN_FREE_GB, f"{free_gb:.1f} GB free (need {MIN_FREE_GB:.0f} GB)",
                 "Free up disk space, e.g. delete old folders in jobs/ and output/")


def listed_names(ffmpeg_list_output: str) -> set[str]:
    """Second column of `ffmpeg -filters` / `ffmpeg -encoders` entry lines."""
    return {parts[1] for parts in (line.split() for line in ffmpeg_list_output.splitlines()) if len(parts) >= 3}


def node_major(version_output: str) -> int | None:
    m = re.match(r"v(\d+)", version_output.strip())
    return int(m.group(1)) if m else None


def _output(cmd: list[str]) -> str:
    try:
        return subprocess.run(cmd, capture_output=True, text=True, timeout=30).stdout
    except (OSError, subprocess.TimeoutExpired):
        return ""


def _dist_version(name: str) -> str | None:
    try:
        return importlib.metadata.version(name)
    except importlib.metadata.PackageNotFoundError:
        return None


def run_doctor() -> list[Check]:
    checks = [Check("python", sys.version_info[:2] == (3, 12), sys.version.split()[0], "Run through `uv run` (Python 3.12)")]
    checks.append(Check("ffmpeg-full", (FFMPEG_FULL_DIR / "ffmpeg").exists(), f"using {ffmpeg_dir()}", "brew install ffmpeg-full"))
    filters = listed_names(_output([ffmpeg_bin(), "-hide_banner", "-filters"]))
    checks.append(Check("ffmpeg libass", {"ass", "subtitles"} <= filters, "ass/subtitles filters", "brew install ffmpeg-full"))
    encoders = listed_names(_output([ffmpeg_bin(), "-hide_banner", "-encoders"]))
    checks.append(Check("ffmpeg libx264", "libx264" in encoders, "libx264 encoder", "brew install ffmpeg-full"))
    major = node_major(_output(["node", "--version"]))
    checks.append(Check("node (yt-dlp JS runtime)", bool(major and major >= 20), f"node v{major}", "brew install node@22"))
    for dist in ("yt-dlp", "yt-dlp-ejs"):
        version = _dist_version(dist)
        checks.append(Check(dist, version is not None, f"{dist} {version}", "uv sync"))
    for module in ("parakeet_mlx", "mediapipe", "scenedetect", "cv2", "pysubs2"):
        checks.append(Check(module, importlib.util.find_spec(module) is not None, f"import {module}", "uv sync"))
    for label, path in (("face model", FACE_MODEL_PATH), ("caption font", FONT_PATH), ("whoosh sfx", WHOOSH_PATH)):
        checks.append(Check(label, path.exists(), str(path.relative_to(PROJECT_ROOT)), SETUP_ASSETS))
    checks.append(check_disk(PROJECT_ROOT))
    return checks


def format_report(checks: list[Check]) -> str:
    lines = []
    for c in checks:
        lines.append(f"{'OK  ' if c.ok else 'FAIL'} {c.name}: {c.detail}" + ("" if c.ok else f"\n     fix: {c.fix}"))
    lines.append("All checks passed." if all(c.ok for c in checks) else "Some checks failed; run the fixes above.")
    return "\n".join(lines)
```

```python
"""`clipper` command: thin orchestration over the stage modules."""
from __future__ import annotations

import argparse
import json
import traceback

from clipper import clips as clips_mod
from clipper import doctor, fetch, package, reframe, render, transcribe
from clipper.clips import ClipError
from clipper.config import ConfigError, load_config
from clipper.env import PROJECT_ROOT, prepend_ffmpeg_to_path
from clipper.fetch import FetchError
from clipper.jobs import Job, is_fresh, job_for, timed


def _cfg(job: Job) -> dict:
    return load_config(job.read_json(job.job_file).get("campaign"), job.overrides)


def cmd_doctor(args: argparse.Namespace) -> int:
    checks = doctor.run_doctor()
    print(doctor.format_report(checks))
    return 0 if all(c.ok for c in checks) else 1


def cmd_prepare(args: argparse.Namespace) -> int:
    video_id = fetch.extract_video_id(args.url)
    disk = doctor.check_disk(PROJECT_ROOT)
    if not disk.ok:
        print(f"error: not enough disk space: {disk.detail}. {disk.fix}")
        return 1
    if args.campaign:
        load_config(args.campaign)  # fail fast on an unknown campaign
    job = job_for(video_id)
    job.ensure_dirs()
    job.write_json(job.job_file, {"url": args.url, "campaign": args.campaign, "cookies_browser": args.cookies_from_browser})
    force = set(args.force or [])
    if "meta" in force or not job.meta.exists():
        with timed(job, "fetch_meta"):
            fetch.fetch_meta(job, args.url, args.cookies_from_browser)
    if force & {"audio", "transcribe"} or not job.sentences_txt.exists():
        if "audio" in force or job.audio() is None:
            with timed(job, "fetch_audio"):
                fetch.fetch_audio(job, args.url, args.cookies_from_browser)
        with timed(job, "transcribe"):
            transcribe.run(job)
    meta = job.read_json(job.meta)
    print(json.dumps({
        "video_id": video_id, "title": meta["title"], "channel": meta["channel"],
        "duration_min": round(meta["duration"] / 60, 1),
        "sentences": len(job.read_json(job.sentences_json)),
        "transcript": str(job.sentences_txt), "meta": str(job.meta),
        "write_clips_to": str(job.clips), "overrides": str(job.overrides),
    }, indent=2))
    return 0


def cmd_resolve(args: argparse.Namespace) -> int:
    job = job_for(args.video_id)
    cfg = _cfg(job)
    result = clips_mod.run(job, cfg)
    for c in result["clips"]:
        print(f"OK    {c['id']}  score {c['score']:>4}  {c['duration']:5.1f}s  {c['title']}")
    for r in result["rejected"]:
        print(f"SKIP  {r['id']}  {r['reason']}")
    print(f"review_first: {str(bool(cfg.get('review_first'))).lower()}")
    return 0 if result["clips"] else 1


def _produce_one(job: Job, clip: dict, cfg: dict, info: dict, meta: dict, words: list[dict], force: set[str]) -> list[str]:
    cid = clip["id"]
    src = job.src_dir / f"{cid}.mp4"
    if "video" in force or not src.exists():
        with timed(job, f"fetch_{cid}"):
            fetch.fetch_section(job, info["url"], clip, meta["duration"], info.get("cookies_browser"))
    crops = job.crops_dir / f"{cid}.json"
    if "reframe" in force or not is_fresh(crops, [src]):
        with timed(job, f"reframe_{cid}"):
            reframe.run(job, clip, words, meta["duration"])
    out = job.out / f"{cid}.mp4"
    if "render" in force or not is_fresh(out, [crops, job.clips_resolved, job.overrides]):
        with timed(job, f"render_{cid}"):
            render.render_clip(job, clip, cfg, words, meta["duration"])
    (job.out / f"{cid}_post.md").write_text(package.post_markdown(clip))
    return [str(p) for p in package.extract_frames(out, clip["duration"], job.frames_dir)]


def cmd_produce(args: argparse.Namespace) -> int:
    job = job_for(args.video_id)
    job.ensure_dirs()
    cfg = _cfg(job)
    if args.fast:
        cfg["render"]["fast"] = True
    info, meta = job.read_json(job.job_file), job.read_json(job.meta)
    words, resolved = job.read_json(job.words), job.read_json(job.clips_resolved)
    results: dict[str, str | None] = job.read_json(job.results) if job.results.exists() else {}
    frames: dict[str, list[str]] = {}
    force = set(args.force or [])
    for clip in resolved["clips"]:
        if args.only and clip["id"] not in args.only:
            continue
        try:
            frames[clip["id"]] = _produce_one(job, clip, cfg, info, meta, words, force)
            results[clip["id"]] = None
        except Exception as exc:  # one broken clip must never stop the rest
            (job.logs_dir / f"{clip['id']}_error.log").write_text(traceback.format_exc())
            first_line = str(exc).splitlines()[0] if str(exc) else ""
            results[clip["id"]] = f"{type(exc).__name__}: {first_line}"
    job.write_json(job.results, results)
    timings = job.read_json(job.timings) if job.timings.exists() else {}
    (job.out / "summary.md").write_text(package.summary_markdown(meta, resolved, results, timings))
    print(json.dumps({"output": str(job.out), "results": results, "qa_frames": frames}, indent=2))
    return 0 if any(v is None for v in results.values()) else 1


def cmd_finish(args: argparse.Namespace) -> int:
    job = job_for(args.video_id)
    removed = package.cleanup(job)
    print(json.dumps({"removed": [str(p) for p in removed], "output": str(job.out)}, indent=2))
    return 0


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="clipper", description="Local podcast clipper")
    sub = parser.add_subparsers(dest="command", required=True)
    sub.add_parser("doctor", help="check tools, models, assets and disk space")
    p = sub.add_parser("prepare", help="download metadata + audio and transcribe")
    p.add_argument("url")
    p.add_argument("--campaign")
    p.add_argument("--cookies-from-browser", dest="cookies_from_browser")
    p.add_argument("--force", nargs="+", choices=["meta", "audio", "transcribe"])
    r = sub.add_parser("resolve", help="validate clips.json and compute exact cut times")
    r.add_argument("video_id")
    d = sub.add_parser("produce", help="download sections, reframe, render, write post files")
    d.add_argument("video_id")
    d.add_argument("--only", nargs="+")
    d.add_argument("--fast", action="store_true")
    d.add_argument("--force", nargs="+", choices=["video", "reframe", "render"])
    f = sub.add_parser("finish", help="delete downloaded media, keep transcripts and outputs")
    f.add_argument("video_id")
    return parser


HANDLERS = {"doctor": cmd_doctor, "prepare": cmd_prepare, "resolve": cmd_resolve,
            "produce": cmd_produce, "finish": cmd_finish}


def main(argv: list[str] | None = None) -> int:
    prepend_ffmpeg_to_path()
    args = build_parser().parse_args(argv)
    try:
        return HANDLERS[args.command](args)
    except (ConfigError, FetchError, ClipError, FileNotFoundError) as exc:
        print(f"error: {exc}")
        return 2
```

````markdown
---
name: clipper
description: Use when the user gives a YouTube podcast or video link and wants short vertical clips (Reels, TikTok, Shorts, X) found, cut, captioned and edited. Runs the local clipper pipeline in this repo; Claude chooses and scores the moments and writes the post copy.

# Clipper

Turns one YouTube link into finished 1080×1920 clips plus ready-to-paste post captions. Code downloads, transcribes, reframes and renders. **You** choose the moments, score them, write the hook text and post copy, and check the result visually.

Run every command from the repo root with `uv run`. Commands are resumable: rerunning skips finished work.

## 0. Preflight

Run `uv run clipper doctor`. If anything fails, run the printed fix (`brew install ffmpeg-full`, `uv sync`, `bash scripts/setup_assets.sh`) and run doctor again. Do not continue until every check passes.

## 1. Read the request

- **URL** (required). One link per run.
- **Campaign:** if the user names one, it must exist as `config/campaigns/<name>.yaml`. If it doesn't, ask for the brief's rules (creator tag, required caption text, required hashtags, length limits, banned topics) and create the file by copying `config/campaigns/example.yaml`.
- **Tweaks** go into `jobs/<video_id>/overrides.yaml`. Write it after `prepare` creates the folder and before `resolve`:

| User says | overrides.yaml |
|---|---|
| "under 30 seconds" | `length: {max: 30, target_max: 30}` |
| "under 15 seconds" | `length: {min: 8, max: 15, target_min: 8, target_max: 15}` |
| "only the best 3" / "just the best clip" | `max_clips: 3` / `max_clips: 1` |
| "no sound effects" | `sfx: {enabled: false}` |
| "no zooms" | `zoom: {enabled: false}` |
| "blue captions" (any colour) | `captions: {highlight_color: "#2D9CFF"}` (pick a fitting hex) |
| "review first" / "let me approve" | `review_first: true` |
| "fast render" | pass `--fast` to `produce` |

## 2. Prepare

`uv run clipper prepare "<url>" [--campaign <name>]`

It prints JSON with `video_id`, the transcript path and where to write `clips.json`. The first run downloads the Parakeet model (~1.2 GB). If the error mentions a YouTube bot check, STOP and ask the user whether to retry with `--cookies-from-browser chrome` (YouTube may flag the Google account).

## 3. Select clips (your job)

Read `jobs/<video_id>/meta.json`, the campaign file (if any), `overrides.yaml` (if any) and the WHOLE `sentences.txt`. Read all of it, in chunks if needed. Never sample. Each line is `S0412 [1:23:45] text`.

1. **Candidates:** list 2–3× `max_clips` candidate moments. For each, quote its opening line and name its hook type: bold claim, surprising fact or number, story opener, contrarian take, direct question, emotional confession, practical tip.
2. **Tighten:** start exactly on the hook sentence (skip preamble, "so", "yeah", throat-clearing). End on the payoff or punchline sentence. Aim for 30–60 s; allowed range is `length.min`–`length.max` (default 20–90 s). Estimate length from the timestamps.
3. **Hard gates.** Drop the candidate if any fails:
   - Standalone: a stranger understands it with zero context (no unresolved "he", "that thing", "like I said").
   - Complete thought with a payoff.
   - Length within range.
   - Respects the campaign (no banned topics).
4. **Score** each survivor 1–5 on `hook` (first 3 s), `standalone`, `payoff`, `emotion` (emotion or controversy), `novelty` (new information or value), `shareability` (would someone send this to a friend?). `score` = (mean of the six ÷ 5) × 10, one decimal.
5. **Rank and pick:** highest score first, no two clips overlapping by more than half, prefer topic variety, keep at most `max_clips` with `score` ≥ `min_score`.

Write `jobs/<video_id>/clips.json`:

```json
{
  "video_id": "<video_id>",
  "clips": [
    {
      "id": "clip_01",
      "start_sentence": "S0412",
      "end_sentence": "S0419",
      "hook_text": "NOBODY TALKS ABOUT THIS",
      "title": "Why going viral means doing what's never been done",
      "score": 8.6,
      "scores": {"hook": 5, "standalone": 4, "payoff": 5, "emotion": 4, "novelty": 4, "shareability": 4},
      "reason": "Bold claim opener, concrete example, punchline at the end.",
      "emphasis_words": ["viral", "never", "million"],
      "post": {
        "instagram": "He spent $1M to learn this 👀 #podcast #business",
        "tiktok": "The $1M lesson nobody tells you #podcast",
        "youtube": "The $1M lesson nobody tells you",
        "x": "Spent $1M to learn this one thing."
      }
    }
  ]
}
```

Field rules:
- `start_sentence` / `end_sentence`: IDs from `sentences.txt`. Never write timestamps.
- `id`: `clip_01`, `clip_02`, … in rank order.
- `hook_text`: 3–8 punchy words shown on screen for the first 2.5 s. Not the same as the first spoken words.
- `emphasis_words`: 2–6 single lowercase words from the clip worth highlighting (numbers, names, emotional words).
- `post.*`: one caption per platform: a short hook line, one sentence of context, up to 3 hashtags. Code appends the campaign's required text, creator tag and required hashtags and caps hashtags at 5, so don't repeat them. X must fit 280 characters.

## 4. Resolve

`uv run clipper resolve <video_id>` prints `OK`/`SKIP` per clip.
- Schema error: fix `clips.json` and rerun.
- Clips skipped and you have strong unused candidates: add them with new ids and rerun.
- If it prints `review_first: true`: show the user a table (id, score, length, title, hook text, source time) and STOP until they approve or edit. Apply edits to `clips.json` and resolve again.

## 5. Produce

`uv run clipper produce <video_id>`: run it with `run_in_background: true` because 8 clips can exceed the 10-minute command limit, then wait for it to finish. One clip only: `--only clip_03`. The JSON output lists `results` (`null` = success) and `qa_frames`.

## 6. QA (your job)

Open every QA frame image with the Read tool. For each clip check:
- the speaker's face is in frame and not cut off;
- captions are readable, inside the frame and not covering the face;
- the hook box is visible at the top in the first frame;
- no black or frozen frames.

To fix, edit `overrides.yaml` (e.g. `captions: {y: 1180}`) and rerun once with `uv run clipper produce <video_id> --only clip_XX --force render` (or `--force reframe render` for framing problems). If it is still wrong, report it. Never hide a failure.

## 7. Finish

Run `uv run clipper finish <video_id>` (deletes downloaded audio and video, keeps transcripts). Then tell the user:
- the folder `output/<video_id>/` and, per clip: score, length, title; plus any failed or skipped clips and why (see `summary.md`);
- each `clip_XX_post.md` holds the ready-to-paste caption for every platform;
- Content Rewards reminder: post natively on each platform, submit the post link within 30 minutes, and don't edit the post after submitting.
````
